# repo-teste

Repositório de teste criado para experimentar a integração entre o GitHub e o Claude, incluindo clonar, editar arquivos, fazer commits e abrir pull requests a partir de uma sessão na nuvem.

## Objetivo

- Validar que o Claude consegue acessar este repositório com permissão de escrita.
- Testar o fluxo de trabalho com branches, commits e pull requests.

## Estrutura

```
repo-teste/
└── README.md   # este arquivo
```

## Como usar

Clone o repositório:

```bash
git clone https://github.com/JoaoVivacqua/repo-teste.git
cd repo-teste
```

## Observações

Este é um repositório apenas para testes. Pode ser apagado ou reaproveitado depois.
